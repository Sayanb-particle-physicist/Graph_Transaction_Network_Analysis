## Project Overview
This project demonstrates a **graph-based analysis of transactions** using Python. It uses the `networkx` library to create, visualize, and analyze graph structures from transaction data.  

The purpose of this project is to showcase **graph neural network readiness and network analysis skills**, relevant for applications in blockchain and large-scale data research.

---

## Features
- Construct a graph from transaction data.
- Compute basic network metrics (degree, centrality, etc.).
- Visualize the transaction network.
- Serve as a foundation for more advanced **graph machine learning tasks**.
